# Task 4 - Rock Paper Scissors

## Description
A simple command-line Rock Paper Scissors game developed using Python as part of the CodSoft Python Programming Internship.

## Features
- User can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Determines the winner based on game rules
- Displays the result
- Maintains the score
- Allows the user to play multiple rounds
- Exit option with final score

## Technologies Used
- Python
- Random module

## How to Run
1. Make sure Python is installed.
2. Open Command Prompt or Terminal.
3. Navigate to this project folder.
4. Run the following command:

python rock_paper_scissors.py
