# Task 2 - Calculator

## Description
A simple command-line calculator developed using Python as part of the CodSoft Python Programming Internship.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero error handling
- Continuous calculations until exit

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed.
2. Open Command Prompt or Terminal.
3. Navigate to this project folder.
4. Run the following command:

python calculator.py
